This repository contains programming work for the DSA assignments. The Assignment-1 questions are maintained in one Jupyter Notebook. Other assignment and laboratory programs are provided as independent Python files.

## Repository structure

- `Assignment-1/Assignment_1.ipynb` - executed notebook for Basics of Python Programming.
- `Assignment-2/Lab-1/` - benchmark algorithms, timing data and plots.
- `Assignment-2/Lab-2/` - prefix average implementations, validation data and plots.
- `Assignment-2/element_uniqueness_methods.py` - three uniqueness methods used in the analysis.
- `Assignment-3/` - recursive, sequence, stack, queue, deque and linked-list programs.

## Requirements

- Python 3.10 or later is recommended.
- `matplotlib` is required to create the lab plots. Install it using `python -m pip install matplotlib`.
- Jupyter Notebook or JupyterLab is required to open and run the Assignment-1 notebook.
